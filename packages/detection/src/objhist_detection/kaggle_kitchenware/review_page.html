Kitchenware box review

How to review
  • Accept when the red box tightly encloses the whole object and the class is right.
  • Reject when the box misses part of the object, covers background or another object, when more than one kitchen object is visible (the others would be unlabeled), or when the object is none of the classes.
  • Change the class when the box is right but the label is wrong, then accept.
  • Every page must be finished before export: validation and test images without a verdict stop the export.
  • Progress is saved in this browser. Download reviews.csv and save it as reviews.csv next to this page; regenerating the page loads it again.
